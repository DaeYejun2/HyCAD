# 대시보드 표시 변경 (2026-11-02)

두 Grafana 대시보드의 탐지기 표시를 비교 탐지기, 시스템콜 빈도 탐지기, 작업량 탐지기로 통일했다. 제목의 부가 설명과 가운데점을 정리하고 입력과 기준선 패널을 제거했다. 각 탐지기의 임계값 산정 방식은 제목 옆 도움말에 둔다.

작업량 그래프는 선택한 서비스의 모든 레플리카를 각각 표시한다. 각 값은 같은 30초 구간의 이벤트 수를 accept와 accept4 이벤트 수로 나눈 값이다. 서비스 전체를 합산하는 모델 판정 계산과 임계값은 변경하지 않았다. 실제 작업량과 변화 점수는 단위가 달라 이 그래프에 점수 임계선 0.20 또는 1을 그리지 않는다.

비교 임계값은 정상 비교 점수 최댓값의 2배이고, 빈도 임계값은 정상 구간에서 관측된 절댓값 z 점수 최댓값이다. 작업량 판정의 정상 참조는 전체 작업량의 정상 구간 중앙값이고, 로그 변화 점수 임계값은 연구 코드의 고정값 0.20이다. 이는 현재 정상 기준선에서 자동 산출하는 값이 아니다.

## 검증

- Mac 및 Ubuntu에서 대시보드 검사 12개 통과.
- 실제 Prometheus와 Loki 조회식 81개 실행 성공. 수동 재생은 현재 상태에서 조회 문법과 분리만 검사했으며 새로운 재생 작업을 시작하지 않았다.
- catalogue와 front-end의 LIVE 및 저장 캡처 자동 재생에서 각각 레플리카 4개 확인. 동일 시각의 이벤트 수와 연결 이벤트 수를 나눈 값이 그래프 값과 일치했다.
- 불완전하거나 오래된 입력, 연결 수 0을 정상값으로 채우지 않는 조회 조건 유지.
- 브라우저에서 제목, 모든 레플리카 범례, 임계값 도움말과 하단 패널 제거 확인.
- 대시보드 파일 갱신만 적용했다. 수집기, 탐지기, 기준선, 실험 환경을 변경하거나 재시작하지 않았다.

기존 대시보드와 생성기 사본은 서버에 보존했다. 전체 서버 재시작이나 새 공격 실험은 이번 표시 변경의 검증 범위에 포함하지 않는다.
